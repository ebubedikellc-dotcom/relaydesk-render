RELAYDESK OWNER CONTROL PANEL

This is the separate owner control panel.

1. Upload this folder to the private control-panel website.
2. Open config.js.
3. The included config.js already points to the Render API service declared in ../render.yaml.
4. Open the control-panel URL and enter the ADMIN_USERNAME and ADMIN_PASSWORD configured on the server.

Do not publish the control-panel password or Telegram credentials.
